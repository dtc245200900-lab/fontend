# Thực hành: Tạo menu ngang Dropdown

## Các tệp
- `index.html`: cấu trúc HTML của menu.
- `style.css`: định dạng menu ngang và menu thả xuống.

## Cách chạy
1. Giải nén thư mục.
2. Mở thư mục bằng Visual Studio Code.
3. Mở `index.html` bằng trình duyệt hoặc dùng tiện ích Live Server.
4. Di chuột vào **Khóa học** hoặc **Tài liệu** để xem menu con. Di chuột vào **Lập trình Backend** để mở menu cấp tiếp theo.

## Đẩy lên GitHub
Mở Terminal tại thư mục dự án rồi chạy:

```bash
git init
git add .
git commit -m "Create horizontal dropdown menu"
git branch -M main
git remote add origin https://github.com/TEN_TAI_KHOAN/TEN_REPOSITORY.git
git push -u origin main
```

Thay URL mẫu bằng URL repository GitHub của bạn. Nếu thư mục đã có remote `origin`, bỏ qua lệnh `git remote add origin`.
