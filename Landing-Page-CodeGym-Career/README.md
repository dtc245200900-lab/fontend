# Landing Page CodeGym Career — Material Design

## Nội dung
- `index.html`: Landing Page responsive.
- `style.css`: giao diện và các điều chỉnh Material Design.
- `script.js`: tương tác menu và form minh họa.

## Cách chạy
1. Giải nén file ZIP.
2. Mở thư mục trong Visual Studio Code.
3. Mở `index.html` bằng trình duyệt hoặc dùng tiện ích Live Server.
4. Cần kết nối Internet để tải Bootstrap, MDBootstrap, Google Fonts và Font Awesome từ CDN.

## Các phần giao diện
- Navbar responsive
- Hero section và nút CTA
- Thẻ lợi ích
- Lộ trình học
- Khu vực dự án minh họa
- Hỗ trợ nghề nghiệp
- Form đăng ký minh họa
- Footer

Nội dung được xây dựng dựa trên các thông tin giới thiệu công khai ở https://codegym.vn/codegym-career/ và được diễn đạt lại cho bài tập giao diện. Các số liệu/thời lượng có ghi chú cần xác nhận lại với đơn vị đào tạo. Đây là sản phẩm học tập, không phải website chính thức của CodeGym.

## Đưa lên GitHub
Tạo repository mới trên GitHub. Mở Terminal tại thư mục dự án và chạy:

```bash
git init
git add .
git commit -m "Build CodeGym Career Material Design landing page"
git branch -M main
git remote add origin https://github.com/TEN_TAI_KHOAN/TEN_REPOSITORY.git
git push -u origin main
```

Thay URL ví dụ bằng URL repository thật. Nếu đã có remote `origin`, bỏ qua lệnh `git remote add origin ...`.
