# Bài tập: Phối màu cho newsletter

## Nội dung
- `newsletter_version1.html`: phong cách tươi mát, hiện đại.
- `newsletter_version2.html`: phong cách ấm áp, sáng tạo.
- `index.html`: trang giới thiệu hai phiên bản, có liên kết để mở từng bản.
- `README.md`: hướng dẫn chạy và nộp bài.

## Cách mở
1. Giải nén ZIP.
2. Mở thư mục bằng VS Code.
3. Nhấp đúp `index.html` hoặc dùng extension Live Server.
4. Chọn từng nút để xem hai phiên bản.

Bootstrap được tải từ CDN nên cần kết nối Internet để hiển thị đầy đủ CSS.

## Nộp GitHub
Tạo repository mới trên GitHub, sau đó mở terminal tại thư mục đã giải nén và chạy:
```bash
git init
git add .
git commit -m "Create two newsletter color themes"
git branch -M main
git remote add origin https://github.com/TEN_TAI_KHOAN/TEN_REPOSITORY.git
git push -u origin main
```
Thay URL mẫu bằng URL repository thật của bạn. Sau khi push thành công, sao chép link repository để nộp bài.
